Jugaaadi Table

A free, open-source React spreadsheet component with formulas, cell merging, 15+ column types, formatting, and CSV export. Built on TanStack Table v8.

Get Started

Jugaaadi Table is an open-source React data grid and editable table component that brings spreadsheet-level functionality to your React app. It supports formulas with cross-sheet references, cell merging, 15+ column types, rich formatting, find & replace, CSV export, undo/redo, and a blank-sheet mode for building spreadsheets from scratch. Written in TypeScript and built on TanStack Table v8, it works with Next.js, Remix, Vite, and any React framework.
